## Runtime physics context

Current `real-runtime-v0` should be described as a damped nonlinear Klein-Gordon-style engine with a Mexican-hat potential. It should not be labeled as CGL. CGL may appear only as historical reference, analogy, or a future candidate framework.

The integrator is `semi-implicit-euler` (also known as symplectic Euler), because each field step updates velocity first and then updates `phi` using the new velocity. It is not leapfrog.

EWMA memory blending and current memory coupling are post-integration state updates, not force or acceleration terms inside the field equation. If a future implementation moves coupling into the acceleration term, `physicsContext` must change accordingly.

## Phase-drive approximation

Phase rotation currently rotates `phiRe` / `phiIm` and, depending on `PHASE_ROTATION_TARGET`, memory fields. It does not rotate `velRe` / `velIm`. Because the runtime is second-order, phase rotation is an operational phase-drive approximation. Adler / Arnold tongue comparisons are qualitative-only and must not be treated as exact model fits.

Use `arnold_tongue_region_candidate`, `phase_boundary_candidate`, and “qualitative Adler-like comparison”; do not claim a confirmed Arnold tongue from PR #28.

## Structural convergence is not automatically mutual convergence

Definitions:

- `structural_convergence`: measured decrease in aligned structural distance.
- `mutual_structural_convergence`: coupling-ON run converges more strongly than its matched coupling-OFF control.
- `common_attractor_relaxation_candidate`: coupling-OFF run also converges substantially, suggesting independent relaxation toward a common attractor.
- `vacuum_attractor_confound`: vortex annihilation, damping, or vacuum relaxation may be reducing A/B distance without mutual attraction.

`structural_convergence` means only that `alignedFieldABDistance` decreased. It does not automatically mean A and B approached because of coupling. Coupling-OFF runs can also converge if both fields independently relax toward a shared vacuum-like attractor.

## `mutual_structural_convergence` requires control evidence

`mutual_structural_convergence` must not be assigned from a single run. It requires comparison evidence such as:

```json
{
  "couplingOnRunId": "run-id-with-coupling",
  "controlRunId": "matched-coupling-off-run-id",
  "alignedDistanceDelta_ON": -0.1,
  "alignedDistanceDelta_OFF": -0.02,
  "comparisonRule": "ON convergence must exceed matched OFF convergence"
}
```

The control should be the matched coupling-OFF run with the same initial layout / seed pair whenever possible. Any tag containing `mutual` must include a matched `controlRunId` or comparison evidence.

## Branch-cut artifact risk in randomized vortex initialization

PR #28 randomized vortex initialization may inflate `initialVortexCount` because the torus phase construction can introduce branch-cut / seam artifacts.

Observation-hygiene tags:

- `branch_cut_artifact_possible`
- `branch_cut_may_inflate_initial_count`
- `vortex_count_absolute_value_caution`

These cautions apply to vortex disappearance and preservation claims, including `vortex_annihilation`, `vortex_preserved_slice_based`, `persistent_vortex`, and `vortex_preserved`. Both disappearance and preservation depend on the initial count and counting method.

PR #28 C vs D comparisons remain useful as relative comparisons because they share the same initialization method. Absolute `initialVortexCount` and `vortexZeroStep` should not be over-interpreted until periodic-consistent vortex initialization is added.

## Central-slice vortex count scope

Current `vortexCount` uses the central z-slice and x-y plaquette winding. For current randomized vortex initialization, phase / winding construction is z-uniform, while amplitude noise is cell-wise and may vary along z. Therefore central-slice `vortexCount` is empirically representative in current PR #28 tests, but it is not a general 3D vortex census.

Future z-dependent or twisted vortex initial conditions must be introduced together with multi-slice or 3D vortex tracking.
