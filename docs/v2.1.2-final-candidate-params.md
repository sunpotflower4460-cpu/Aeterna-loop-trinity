- Candidate status: provisional; not ready to become defaults
- Confidence: low overall, because HISTORY_ALPHA and Memory Coupling still need rescan; medium for the pheromone-localization component
- Based on:
  - `experiments/history-alpha-scan-results.json`
  - `experiments/memory-coupling-micro-scan-results.json`

## Pheromone

| param | value | reason |
|---|---:|---|
| PHEROMONE_DIFFUSION | 0 | Best local trace rows kept active ratio low without requiring diffusion. |
| PHEROMONE_DEPOSIT_THRESHOLD_RATIO | 0.95 | Recorded as the strict threshold setting; threshold is neutral for current top-percent modes but this value is safest to carry forward. |
| PHEROMONE_DEPOSIT | 0.02 | Produced the strongest non-saturated top-10 trace in the scan. |
| PHEROMONE_DEPOSIT_MODE | top-10-percent-amplitude | Keeps deposition local (`activeRatio≈0.099609`) without collapsing to no trace. |

## Not Selected

- HISTORY_ALPHA rows with `MEMORY_WEIGHT >= 0.08`: memory-field difference was too small.
- Any HISTORY_ALPHA row as a stable final default: all rows remained below the requested `0.05–0.3` memory-trace range.
- Weak Memory Coupling rows: A/B distinction remained, but A/B did not meet enough.
- Treating `fieldABDistance_end > 0.1` as success: this would accept separation rather than meeting.
- Pheromone rows with zero trace strength: no local residue remains.
- Broad all-above-threshold pheromone rows: less clearly path-like than top-percent deposition.
- Any v2.2 feature implementation: coherence UI, force-based Pulse, true gradient feedback, Trinity UI, archive/replay, Bhramari, Katakamuna, morphic bias, and practice mode remain out of scope.

## Notes for v2.2

v2.2 should only begin after these candidate params are stable enough to serve as a base for:

- Coherence Score
- force-based Pulse comparison
- pheromone gradient feedback
- Trinity visualization

Current decision: do not start v2.2 yet. Run an additional v2.1.2 scan for HISTORY_ALPHA and Memory Coupling first, then validate the combined candidate.
