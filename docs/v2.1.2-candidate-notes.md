# AeternaLoop-Trinity v2.1.2 Candidate Notes

## Theme

v2.1.2 is a tuning phase.

The aim is to loosen over-strong memory, over-strong fusion, and over-diffuse trace fields before adding v2.2 features.

## Safety baseline already checked

The current tuning scripts assume the v2.1.2 safety pass is present:

- EWMA velocity blend no longer divides the velocity pull by `DT`.
- A/B relation docs use `R_AB_orderDifferenceRatio` as the primary name and keep `R_AB_relative` as a compatibility alias only.
- Energy wording separates `fieldEnergyProxy` from pheromone memory-style `pheromoneEnergyL2`.
- Surrogate/headless scans are recorded separately from future real `64^3` validation.

## Baseline candidate

`GAMMA = 0.005` is used as the current baseline candidate for these scans.

This is not an ideal-value claim. It means only that the v2.1.1 experiment family found relatively smaller energy growth while amplitude stayed near VEV.

## Experiment 010: HISTORY_ALPHA scan

Script:

```bash
npm run experiment:history-alpha-scan
```

Output:

```text
experiments/history-alpha-scan-results.json
```

Scan values:

- `HISTORY_ALPHA`: `0.04`, `0.02`, `0.01`, `0.004`, `0.002`
- `MEMORY_WEIGHT`: `0.04`, `0.08`, `0.12`, `0.16`

Success candidate criteria:

- Vortices remain or vortex lifetime clearly extends.
- `memoryFieldDifferenceA_end` / `memoryFieldDifferenceB_end` remain roughly `0.05–0.3`.
- `amplitudeMeanA_end` / `amplitudeMeanB_end` do not collapse or inflate far from VEV.
- `fieldEnergyProxy_end` does not show rapid amplification or damping relative to the start.
- Memory does not behave as a current-field near-copy.

## Run metadata requirement

Each v2.1.2 scan result JSON includes:

```js
runMeta: {
  experimentName,
  version: "v2.1.2",
  createdAt,
  commit,
  branch,
  seed,
  maxSteps,
  sampleInterval,
  runType,
  gridSize,
  dynamicsType,
  notes
}
```

Current scripts record `runType: "surrogate-headless"` and `dynamicsType: "diagnostic-surrogate"`.
Future real validation must record `runType: "real-64"` and should not be mixed with these surrogate results.
