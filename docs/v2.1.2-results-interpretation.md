# AeternaLoop-Trinity v2.1.2 Results Interpretation

## Summary

The three v2.1.2 result files were present and readable. All three runs are `surrogate-headless` / `diagnostic-surrogate` scans on `gridSize=8`, so the interpretation below is useful for ranking but is not a real `64^3` validation claim.

The main finding is mixed: pheromone localization now has usable local-trace candidates, but HISTORY_ALPHA and Memory Coupling still need one more v2.1.2 tuning pass. HISTORY_ALPHA preserved vortices and stayed energy-stable, yet every row remained below the provisional `memoryFieldDifference` trace range. Memory Coupling preserved vortices and distinction, yet every row stayed above the requested `fieldABDistance_end = 0.01–0.1` meeting band.

Scoring used lightweight ranking aids only:

- `historyAlphaScore = vortexPersistenceScore * 0.30 + memoryTraceScore * 0.30 + amplitudeStabilityScore * 0.20 + energyStabilityScore * 0.20`
- `memoryCouplingScore = abMeetingScore * 0.35 + nonCollapseScore * 0.25 + vortexPersistenceScore * 0.20 + energyStabilityScore * 0.20`
- `pheromoneLocalizationScore = localityScore * 0.35 + nonUniformScore * 0.25 + saturationSafetyScore * 0.20 + traceStrengthScore * 0.20`

### Interpretation

All HISTORY_ALPHA rows preserved the initial four vortices to the end of the run, and the field-energy proxy changed only mildly from `102.182859` to the `102.503075–104.055335` range. Amplitude also did not collapse: `amplitudeMeanA_end` stayed in the narrow `0.380077–0.389183` band, with `amplitudeStdA_end` around `0.227530–0.236099`.

The failure point is trace separation. The requested provisional memory-trace range was `0.05–0.3`, but the whole scan produced only `memoryFieldDifferenceA_end = 0.013362–0.041552`. That means the EWMA memory is not collapsing the dynamics, but it still behaves too close to a current-field copy or near-frozen trace for this criterion. The best row, `HISTORY_ALPHA=0.002 / MEMORY_WEIGHT=0.04`, is therefore a provisional starting point, not a final accepted parameter.

`memoryFieldDifferenceB_end` and B-side amplitude/order values are `null` in this single-field HISTORY_ALPHA surrogate, so the next pass should preserve the schema while adding an A/B or real-loop validation when available.

### Recommended Params

- `HISTORY_ALPHA: 0.002`
- `MEMORY_WEIGHT: 0.04`
- `MEMORY_WEIGHT_MODE: fixed`
- `MEMORY_VELOCITY_SCALE: 0.1`
- Confidence: low / provisional

### Rejected Patterns

- `MEMORY_WEIGHT >= 0.08`: progressively reduces memory-field difference below the already-low best rows.
- `HISTORY_ALPHA=0.04`: stable, but not separated enough from the current field.
- Any scanned row as a final value: vortices survive, but none reaches the non-copy trace band.

### Need Rescan?

Yes. Suggested next HISTORY_ALPHA scan: test `MEMORY_WEIGHT` below `0.04` and `HISTORY_ALPHA` at or below `0.002`, with the same diagnostics plus a longer run if runtime allows.

### Interpretation

The micro scan avoided the v2.1.1 failure mode of complete A/B identity collapse: `memoryABDistance_end` never pinned to zero, amplitude standard deviation remained around `0.2267–0.2327`, and all rows retained `8/8` vortices. However, the scan also did not reach the desired meeting-with-distinction band.

The requested target was `fieldABDistance_end = 0.01–0.1`. The closest row was `MEMORY_COUPLING_WEIGHT=0.5 / COUPLING_G=0.05`, with `effectiveMemoryCoupling=0.025` and `fieldABDistance_end=0.142335`. This is a clear movement from `0.231966`, but still too separate for acceptance. We should not call weaker rows successful just because they are safe; they preserve distinction by failing to make A/B meet.

`R_AB_orderDifferenceRatio` is not a useful success signal in this scan because it starts near zero and ends at tiny values. The distance metrics carry the actual interpretation here.

### Recommended Params

- `MEMORY_COUPLING_WEIGHT: 0.5`
- `COUPLING_G: 0.05`
- `effectiveMemoryCoupling: 0.025`
- Confidence: low / provisional closest row only

### Rejected Patterns

- Weak effective coupling `<= 0.0125`: A/B remain too separate.
- Treating tiny `R_AB_orderDifferenceRatio_end` values as proof of meeting: distance metrics disagree.
- Complete identity remains rejected in principle, although this particular micro scan did not hit it.

### Need Rescan?

Yes. Suggested next scan: focus just above `effectiveMemoryCoupling=0.025` while monitoring for the lower bound of collapse, for example stronger `MEMORY_COUPLING_WEIGHT` / `COUPLING_G` combinations that can enter `fieldABDistance_end = 0.01–0.1` without driving `memoryABDistance_end` or amplitude variance to zero.

### Interpretation

Unlike the earlier pheromone-field result where `pheromoneActiveRatio` could become global background, this localization scan found many non-fog candidates. The selected candidate is `PHEROMONE_DIFFUSION=0`, `PHEROMONE_DEPOSIT_THRESHOLD_RATIO=0.95`, `PHEROMONE_DEPOSIT=0.02`, and `PHEROMONE_DEPOSIT_MODE=top-10-percent-amplitude`.

The selected row leaves a visible but local trace: `pheromoneActiveRatio_end=0.099609`, `pheromoneSpatialEntropy_end=0.629979`, `pheromoneStd_end=0.006243`, `pheromoneMax_end=0.033860`, and `pheromoneEnergyL2_end=0.023830`. It is not saturating the max and is not active everywhere. Entropy is slightly above the scoring target's preferred upper band, but active ratio and nonzero standard deviation indicate a path-like residue rather than a uniform fog.

A scan caveat matters: for `top-10-percent-amplitude` and `top-5-percent-amplitude`, the current deposit utility ranks cells by amplitude, so threshold ratios tie. The stricter `0.95` threshold is recorded for consistency, but the mode is doing the selection in these rows.

### Recommended Params

- `PHEROMONE_DIFFUSION: 0`
- `PHEROMONE_DEPOSIT_THRESHOLD_RATIO: 0.95`
- `PHEROMONE_DEPOSIT: 0.02`
- `PHEROMONE_DEPOSIT_MODE: top-10-percent-amplitude`
- Confidence: medium / surrogate

### Rejected Patterns

- Zero-deposit/no-residue rows: no trace remains.
- Broad `all-above-threshold` rows with higher active ratios: not global fog, but less path-like than top-percent deposition.
- Using threshold ratio as the deciding factor for top-percent modes: it is effectively neutral in the current scan helper.

### Need Rescan?

No immediate pheromone-only rescan is required before the next combined v2.1.2 pass. A later combined run should still verify that this local-trace setting remains stable when paired with retuned memory and coupling.
