# v2.1.2 Winding / Memory / Phase-Slip Audit

## Purpose

This audit formalizes recent winding, memory, and phase-slip smoke findings into reproducible repository artifacts. The question is not merely whether `W=1` persists. The question is what determines the outcome when winding is damaged, destroyed, restored, transferred, or rewritten.

Guiding sentence: **The field may carry the moment. Memory may bias where the field returns. Measure both, and do not confuse either with life.**

The audit records global x-axis winding persistence, phase-slip thresholds, memory-mediated restoration candidates, memory-biased basin selection, field-memory bidirectional rewriting, and one-sided-winding `W=1 × W=0` coupling transitions in the current damped runtime.

## Runtime cost, modes, and parameter lineage

The audit runner is `scripts/run-v212-winding-memory-phase-slip-audit.js`.

- A separate `--runtime-limited` smoke mode remains available for quick local checks, but it is not the committed main evidence artifact.
- The canonical lineage is `parameterLineage: "exp023-real"`, with `MEMORY_WEIGHT=0.0075`, `HISTORY_ALPHA=0.002`, `MEMORY_BLEND_VELOCITY=true`, and `MEMORY_VELOCITY_SCALE=0.1`.

All winding / memory / phase-slip runs use `phaseConstructionMode: "legacy-torus-atan2"`. This PR does not compare initializer hygiene modes.

## Observer context

Every run record includes `physicsContext`, `observerContext`, and `parameterLineage`. The observer measures x-axis line winding across all `(y,z)` lines, not full 3D vortex-core topology. The line-wise winding histogram is therefore a global-winding and activity observer, especially during tangled phases.

Mode powers use the exact formula:

```text
P_m = |mean(phi * exp(-i2πmx/N))|^2
```

The JSON records `P0`, `P1`, `P2`, normalized powers over `P0+P1+P2`, `P1OverP0`, and `P2OverP0` for both field and memory.

## Prior registered expectations

These are expectations, not success criteria. Prediction failures are evidence.

- PR #30 periodic vortex initialization prediction: new initializer hygiene should remain separate from this audit; this audit should record `legacy-torus-atan2` rather than retesting initializer comparisons.
- `W=1` and `W=2` baseline persistence should hold through the tested horizon.
- `W=1 + ε=0.5` should usually persist or recover; `W=1 + ε=1.2` should expose phase-slip / recovery thresholds.
- Matched memory-off `W=1 + ε=1.2` was expected not to recover as reliably as memory-on over the long horizon.
- Clean `W=0` memory was expected to bias a damaged `W=1` field toward `W=0`.
- Clean `W=2` memory at low memory weight was expected to fail to overwrite the field, while stronger weights around `0.03–0.05` could push the field toward `W=2`.
- One-sided-winding `W=1 × W=0` coupling was expected to show low-`g` plateau, intermediate merge, and high-`g` double-slip / transfer candidate.
- Pure `W=0 + ε=1.2` noise was expected not to create stable `W=1` recovery.

## Memory ON/OFF control

Memory OFF disables `MEMORY_ENABLED`, sets `MEMORY_WEIGHT=0`, disables memory coupling, and leaves buffers present for observation. In the default lightweight artifact, the matched short memory-off run has final dominant `W=1` but only dominant fraction `0.39160156`, so it is a partial recovery / tangled outcome. The longer memory-off control ends at final dominant `W=0`. This supports cautious language only: memory may bias basin selection, but the field can also self-order or slip without active memory under some tested conditions.

Preferred interpretive tag: `memory_biased_basin_selection`.

Avoided claim: memory is an infallible ledger.

## Interpretation by claim level

### Measured

- Raw field and memory winding histograms.
- Field and memory mode powers.
- `minAmp`, `meanAmp`, `maxAmp`.
- Kinetic energy proxy.
- Slip onset samples where detected.
- Field/memory winding transitions.
- A/B raw and gauge-aligned distance metrics for coupling runs.

### Observed

- `W=1` and `W=2` persisted through the default lightweight `exp023-real` baseline horizon.
- Clean `W=0` memory biased the damaged field to final `W=0` in D1.
- Low D2 memory weight let the field rewrite clean `W=2` memory back to `W=1`; higher tested weights wrote `W=2` into the field.
- One-sided-winding bidirectional coupling produced plateau, single-slip merge, and synchronized double-slip candidate regimes under tested `g` values.

### Interpretive

- Memory biases basin selection rather than acting as an absolute ledger.
- Memory-mediated restoration remains a candidate mechanism, not a proof.
- Coupling may open amplitude holes that permit phase slips.
- Strong memory/coupling may enable uphill winding transfer under tested conditions.
- Field and memory can write into each other with asymmetric apparent time constants.

### Speculative / future-map only

Q-ball-like structures, vortex rings, helicity, biological life, consciousness, and heart-like systems are outside this PR's implementation and evidence level.

## Limitations and future work

- Winding histograms measure x-axis global line winding only.
- During tangled phases, line-wise W values are activity indicators rather than full topology classification.
- Phase slip is inferred from winding loss/recovery, minAmp collapse, and mode power changes.
- This audit does not implement full 3D vortex-core tracking.
- No new runtime physics terms, potential terms, driven feeds, Q-ball physics, vortex ring tracking, helicity tracking, or full 3D vortex tracking are introduced.
- Future work: add time-series L2 distances (`mean |field-memory|`, `mean |field-targetW|`, `mean |memory-targetW|`), a coupling control with `MEMORY_WEIGHT=0`, denser `g` values around `0.0125`, `0.015`, and `0.025`, low-amplitude winding validity residuals, and a later CI runtime-limited smoke command.

## Cautious recommendation

Use the checked-in default lightweight `exp023-real` artifact as a reproducible 32³ audit snapshot. The next PR should densify only the memory-weight threshold and one-sided-winding coupling transition bands, add a coupling control with `MEMORY_WEIGHT=0`, and add time-series field/memory/target L2 distances before promoting any candidate transfer/exchange classification. Do not promote candidate tags to exact topology proof or biological interpretation.
