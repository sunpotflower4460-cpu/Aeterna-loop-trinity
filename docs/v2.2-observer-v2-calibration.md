# v2.2 Observer V2 Calibration

## Purpose

Observer V2 calibrates the measurement ruler before it is used for later regime work. It adds L2 distance traces plus x-line reliability metrics so future audits can distinguish clean recovery, partial recovery, merge, transient swap windows, memory-mediated behavior, and low-confidence winding lines without changing runtime physics.

## Scope

This calibration adds observers and calibration artifacts only. It does not add new physics, reinterpret historical artifacts, or create new regime claims. Tier 1 is synthetic known-answer observer testing. Tier 2 is representative v2.1.2-style physics-scenario calibration with pre-registered soft expectations and hit/miss reporting.

Official artifacts:

- `experiments/v2.2-observer-v2-calibration-results.json`
- `experiments/v2.2-observer-v2-calibration-summary.json`

The official artifacts use `runMode: "lightweight"`; they are not runtime-limited smoke outputs.

## Metrics list

Single-field samples record dominant field and memory winding, dominant fractions, mode powers, field and memory amplitude stats, raw and gauge-aligned field-memory distance, field-target distance, memory-target distance, `thetaStar` values, line reliability metrics, and an effective pull work proxy.

Coupling samples additionally record A/B dominant winding and fractions, memory A/B winding, raw and gauge-aligned field A/B distance, raw and gauge-aligned memory A/B distance, same-side and cross-side field-memory distances, min amplitudes, and A/B `thetaStar` values.

## Formulas and conventions

### Distance definitions

Raw distance is:

```text
sqrt(mean |a - b|^2)
```

across finite complex samples. Gauge-aligned distance uses the shared repository gauge-alignment convention to choose `thetaStar`, then applies that angle to the second field before evaluating the same L2 formula.

### Amplitude convention

Analytic winding targets use the stationary-amplitude reference:

```text
sqrt(max(0, vev^2 - (2 - 2 cos(2πW/N)) / lambda))
```

The artifact records `targetAmplitudePolicy: "stationary-amplitude-reference"`. This avoids an artificial distance floor that would be produced by comparing relaxed winding fields against amplitude-1.0 references.

### `thetaStar` sign convention

`thetaStar` is the angle applied to the second field as `exp(+i thetaStar)` so that it best aligns to the first field. In the Tier 1 phase-offset regression, the second `W=1` field is offset by `π/5`, and the measured `thetaStar` is `-π/5` within tolerance.

### Winding validity and reliability convention

Observer V2 evaluates x-axis `(y,z)` lines only. For each line it records `lineMinAmp`, `lineMaxAbsPhaseStep`, `lineMeanAbsPhaseStep`, `nearPiStepCount`, aggregate `nearPiStepFraction`, `maxNearPiStepCount`, and `totalNearPiStepCount`. A step is near-π when:

```text
abs(Δφ) > π - nearPiMargin
```

The calibration records `validityAmpThreshold: 0.1` and `nearPiMargin: 0.3`. Lines with `lineMinAmp < validityAmpThreshold` are counted as invalid.

The closed-loop integer residue is retained only as `closedLoopFloatResidualMean` / `closedLoopFloatResidualMax`. It is a floating-point sanity check only, not a reliability signal. Reliability is estimated from low-amplitude lines and near-π phase steps.

### Effective pull work proxy

The effective pull work proxy is:

```text
workProxy = coefficient * distance
```

The basis is that blend weight `w` and coupling `g·cw` are dimensionless per-step pull coefficients of the same functional form:

```text
phi += k * (target - phi)
```

The proxy is not physical energy; it only makes coefficient × target-distance dependence visible.

## What Observer V2 can and cannot claim

Observer V2 can report finite-horizon measurement traces: L2 distances, gauge-aligned distances, sign-regressed `thetaStar`, line reliability metrics, low-amplitude invalid-line counts, near-π phase-step counts, and coefficient × distance work proxies.

Observer V2 traces are measurement aids. They do not prove exact topology, biological life, consciousness, agency, or permanent survival claim. Observer V2 is limited to x-axis line winding and does not replace a full 3D topology observer.
